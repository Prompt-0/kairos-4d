An interactive multi-timeline detective puzzle engine spanning three interconnected eras: **1924 (Noir)**, **2024 (Present)**, and **2124 (Cyberpunk)**. Players investigate a century-spanning locked-room mystery by manipulating cause-and-effect relationships across time.

---

## ⏳ Engine Mechanics & Architecture

- **Multi-Timeline Causality Graph**: State changes made in the past (e.g. concealing a ledger in 1924) dynamically ripple forward, altering physical artifacts, room layouts, and witness testimony in 2024 and 2124.
- **Deduction & Hypothesis Matrix**: Node-based deduction board where players connect temporal clues, forensic timeline evidence, and motive nodes to reach logical conclusions.
- **Paradox Resolution Engine**: Deterministic dependency validation preventing contradictory causality loops and calculating downstream butterfly effects.
- **Adaptive Chrono-Audio**: Synthesizer audio engine that shifts ambient instrumentation based on the active timeline—from warm 1920s gramophone crackle and jazz chords, to clinical modern drones, to 2120s gritty cyberpunk FM synth.
- **Automated Test Coverage**: 14 Vitest unit tests verifying timeline causality propagation, deduction tree solvers, and narrative state graphs.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Prompt-0/kairos-4d.git
cd kairos-4d

# Install dependencies
npm install

# Start development server
npm run dev

# Run unit tests
npm run test

# Build production bundle
npm run build
```
